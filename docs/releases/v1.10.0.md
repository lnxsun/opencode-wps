# Release Notes — v1.10.0

- **发布日期**：2026-09-22
- **上一版本**：v1.9.35
- **语义化版本性质**：Minor（含**用户可见的行为变更**：校对默认规则集收缩）
- **关联**：Issue #352 · PR #376（merge commit `545cdf7`）

## 一、本次发布内容

### Changed

- **校对源码压缩方案 A+B+D（PR #376）** — 承接 A/B/C/D 四项可砍空间，按指令只做 A+B+D，**不碰 C**（报告诚实性逻辑）：
  - **A 风格偏好规则默认关闭**：`Rule.optionalGroup` 新标记，**30 条**规则（口语化 17 + 格式类 13）标为可选组，
    规则总数仍 80（默认启用 50）。`runBasicProofreading(..., includeOptional=false)` 默认过滤。
    ⚠️ **行为变更（用户可见）**：默认校对不再报口语化/格式类问题（原报告里低价值 issue 主要来自此处），
    能力在代码层保留（`includeOptional` 入参，当前无用户可达路径）。
  - **B 归一化投影层合一**：`isFixActionInferred` + `classifyFixActionInference` + `describeFixAction` 三投影合一为
    `classifyFixActionInference`；`describeFixAction` 无生产消费方，随刀删除。
    `FORMAT_TYPES` 改派生自 `TYPE_METRIC_MAP` 单源（消第二份定义）。唯一裁决点仍是 `resolveFixAction`。
  - **D store 并入 types**：删除 `proofread-store.ts`（仅余 `PROOFREAD_BATCH_MAX` 常量）并入 `proofread-types.ts`。
  - **体量闸门棘轮收紧**：校对源码 **1841 → 1824 行**（9 文件），`LIMITS === RATCHET === ACHIEVED === RATCHET_INITIAL === 1824`。
  - **方案 C 零改动**：报告「三处正交状态」诚实性逻辑（`proofread-report-copy.ts` / `summarySection`）未动。

### 随本线一并进 main 的守卫重构（Issue #352 系列刀，均无用户可见行为变更）

- 第九刀：删轴 I「方向 2 / AC4」两个零判别力自指判据 + 清单覆盖/豁免死字段（PR #371）。
- 第十刀：K7 守卫整体删除，两条判据（标签↔`GUIDE_MAP` 键双向闭合 / 指路文案预算）并入轴 I（PR #370）。
