## 一、本次发布内容

### Added

- **P2「覆盖全文后禁止推进」不变量新增 `scripts/` 层行为守卫（Issue #400）** — 该门禁的
  「单批文档在校对前不被拦」不变量此前**只由 `tests/` 承载**：把判据整块删除后，`tests/` 察觉（exit 1），
  但 `scripts/` 下五个守卫**全 exit 0**（Issue #395 门禁遮蔽探针登记的遗留项 W-1）——
  属铁律 24 第 7 维「不变量必须归属门禁」缺口的典型形态。本次把该不变量落成**可独立执行**的守卫：

  | 落点 | 内容 |
  |---|---|
  | `scripts/validate-proofread-p2-invariant.js` | **行为**断言（非形态）：`scripts/` 层加载 **prod** `governance.js`，注入真实 `before`/`after` 调用链 |
  | `scripts/lib/proofread-p2-invariant.js` | 判据纯函数（模块内无仓库路径字面量） |
  | `scripts/lib/guard-scopes.js` | 登记守卫覆盖源与 3 落点常量 |
  | `scripts/lib/semantic-anchor-manifest.js` | 登记第 10 语义键 `proofread-p2-invariant` |
  | `package.json` | 接入 `preflight` + 新增 `validate:proofread-p2-invariant` |

- **两条行为断言（含对偶面）**：
  - ① 单批（≤200 段）文档「首批取段即达文末」时，③取文本 + ④校对**不被 P2 拦**（否则闭环死锁）；
  - ② 对偶面：多批末批上报（覆盖全文）后继续推进**仍被 P2 拦**（防「为过 ① 而整块删门禁」）。
