# Release Notes — v1.14.0

- **发布日期**：2026-09-28
- **上一版本**：v1.13.0
- **语义化版本性质**：Patch+（**纯缺陷修复**，无对外接口/配置/工具集变更：工具面仍 238 注册 / 251 COM Actions / 15 内置）
- **关联**：Issue #395 · PR #397（merge commit `ade19b3`）
- **主题**：修复「校对抽风」——2 次真实校对会话暴露的 7 类根因（治理层与 MCP 服务端硬缺陷）

## 一、本次发布内容

### Fixed

- **修复「校对抽风」7 类根因（Issue #395）** — 两次真实校对会话（s1：341 次工具调用 / 28 处报错；
  s2：54 次调用 / 21 处报错）暴露的不是 AI 偷懒，而是 **通道层 → 归一层 → 参数层 → 状态机层**
  四层缺陷叠加，把 AI 逼进「每一步都被门禁拦、只能靠猜」的死角。逐条修复：

  | 根因 | 现象 | 修复 |
  |---|---|---|
  | **RC-0** 内置名归一为 `null` | SKILL 教 AI 调的内置 `wps_get_active_document` 不被归一函数识别 ⇒ `docInfoFetched` 永不置位 ⇒ 后续恒报「请先调用 getActiveDocument」 | `normalizeToolCall` 补**内置名映射**（Word/Excel/PPT） |
  | **RC-0′** 输出形态只认文本 | 内置名成功体是 JSON，after 钩子只按文本正则解析 ⇒ `totalParagraphs=0` | after 钩子改「**先试 JSON、回落文本**」 |
  | **RC-1** 同一参数两套键名 | schema 只认 `start_offset`，门禁读驼峰 `startOffset` ⇒ 传哪个都过不了另一层（s1 里 17 次报错） | 收敛为**单点** `normalizeStartOffset`，两条门禁共用 |
  | **RC-2** 单批文档闭环死锁 | ≤200 段（单批）文档首批取段即「覆盖全文」⇒ P2 拦下推进类全部 5 个工具，报告又要求先有痕迹 ⇒ **死锁** | P2 加前置 **`batchAccumulatedThisBatch`**（仅本批已上报后生效） |
  | **RC-3** `enableTrackChanges` 谎报 | `active` 与 `trackChanges` 同属一次往返且回抄入参 ⇒ 写入被拒仍回显「已开启」 | handler **独立往返回读**真实状态，不一致即 `success:false` |
  | **RC-4** `type` 词表缺失 | AI 写英文 type 被静默落「未分类」不计六维 ⇒「8 处问题 / 六维全 10.0」自相矛盾 | 未命中不再原样保留；SKILL 给出**派生自单源**的词表来源 |
  | **RC-5** 通道故障文案误导用户 | 失败文案「请确认文档已打开 / 切到前台」与同帧 `<wps-context>`（已证明文档已开）**直接矛盾** | 改为「**COM 通道未挂接，可调用 openDocument 重连**」 |

### Added

- **整链端到端回归 `tests/governance-proofread-e2e-395.test.js`（659 行，17/17）** — 兑现用户
  「测试环节全链条真正跑通、不要左右互搏」的要求：
  - **A1 同一入口**：`runFullChain()` 一条链串 ①取文档→②取段→③取文本→④校对→⑤开修订→⑥确认→⑦替换→⑧上报。
  - **A2 名实一致**：链中工具名/参数键名 = `SKILL.md` 教 AI 用的那套（内置名 + 下划线 `start_offset`）。
  - **A3 变异自证**：把 5 处修复点逐个整块删除，对应用例**必须由绿转红**；另补 3 条**负向对照**。
- **MCP 单测**：`proofread-track-changes-readback.test.ts`（4/4，含删判据自证）、
  `proofread-normalize-contract.test.ts`（未命中 type 不再静默降级）。

### Changed

- **`preflight` 纳入 MCP 集成测试** — 修复评审发现的**门禁面 < 测试面**根因：`preflight` 原先不含
  MCP 集成测试，导致本 PR 引入的 `skills-consistency` 回归**单测层看不见、CI 会红**；新增断言锁定该段。

  同形 ⇒ 既有缺陷，按铁律 17⑨ **不并入本 PR**，建议独立 Issue 跟踪。
