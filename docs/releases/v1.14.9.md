## 一、本次发布内容

### Fixed

**六项原始缺陷**（逐条来自会话存档的可核实痕迹，非推测）：

1. **类型词缺键 ⇒ 已修复项落「未分类」不计六维** —— `3W`→`3万`、`15W`→`15万` 已实际改进文档并产生修订，
   却因 `TYPE_METRIC_MAP` 无 `网络用语` 键而连六维都没进；段 37 缺「三、」同理（无 `编号不连续` 键）。
   修法：补两键 → `consistency` / `format`（单源 `proofread-normalize.ts`，与 SKILL 的 45 个类型词、
   六维分组 23/8/2/2/9/1 逐项相等）。
2. **裸占位恒漏检** —— 原占位规则**强制**后接「公司/项目/部门/单位」，故段 36 的裸 `xxxxx` 只能靠 AI 兜。
   新增裸 `x{3,}` 规则（左右排字母，防吃 `Maxxxx`）。
3. **报告「AI 智能校对 0 处」与事实相反** —— `source` 缺省兜底 `mcp`，而 SKILL 从没要求传 `source`。
   修法：SKILL 写死 `source` 必填（Layer 2 自产传 `ai`）。
4. **落盘失败后改传 `output_file` 重试恒报「未找到会话」** —— 原实现 `!outputFile` 时**也**回收会话，
   把「重试落盘」这条自纠路自己掐死。修法：**仅真正落盘成功**才回收。
5. **落盘报告被 `Path not allowed` 拦** —— `write_file` 白名单只有主目录 + 临时目录。
   修法：抽单源 `buildWriteRootsWithDocDir`，`write_file` 与报告落盘**同口径**并入当前文档所在目录。
6. **P1「批次不连续」拦死「已覆盖区间只读重读」** —— 会话中 AI 只想回看 19-27 段核对坐标，被拦后
   改道做偏移取证、耗十余轮。修法：按 `end ≤ 已覆盖段` 放行（越界仍拦）。

**评审-修复循环（10 轮，每步均在 PR #422 独立留痕）另修六项**：

## 三、条件项与既有债（未闭环，如实披露）

- **类型词用得对不对不校验** —— 只校验存在性与维度归属。
- **`网络用语` 规则只认「数字 + W/w + 中文量词」**（`3W路`）；裸 `100W 灯泡` 不报（宁可少报不可误报）。
- **`source` 缺省仍保守兜底 `mcp`** —— 根治靠 SKILL 让 AI 传 `ai`；**未做**启发式猜测改判
  （那会造出更难查的错）。
- **`wps_common_save`（saveAs）未并入文档目录**，与 `write_file` 现口径不一致 —— 既有差异，
  非本 PR 引入，如需统一建议单开 Issue。
